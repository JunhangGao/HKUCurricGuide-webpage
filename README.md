## 🌐 What this repository contains

A static showcase: problem and users, workflow, actual corpus-import screenshots, recorded evaluation, failure cases, setup links and team members. It contains no Python backend, live model integration, API key or runtime database. HTML/CSS design and documentation were prepared with AI assistance and team-supplied evidence.

## 🚀 Hosting / update

GitHub Pages publishes `main` from the repository root. `index.html` and its relative CSS/assets work under the repository URL. To preview locally, open `index.html` in a browser. Update the separate presentation/demo URLs in the `videos` section when the team supplies them; their current status is clearly marked on the page.

## 📚 Evidence and limits

The pictures are actual v2.0 Corpus import/PDF-preview test captures, not screenshots of live model answers. The Windows CS live workflow is described from team-shared screenshots. The historical 18-question/two-mode comparison and macOS verification link to records in the application repository. 74 offline tests are not a factual-accuracy percentage.
